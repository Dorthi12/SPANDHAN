# Digital Signal Processing (DSP) Methods

The MATLAB engine provides implementations for key DSP transformations:

- **FFT**: Fast Fourier Transform for spectral frequency content.
- **STFT**: Short-Time Fourier Transform for time-frequency analysis.
- **Wavelet**: Continuous and Discrete Wavelet Decompositions (`db4`).
- **FIR Filtering**: Finite Impulse Response digital filtering.
- **IIR Filtering**: Infinite Impulse Response (Butterworth) filtering.
- **Convolution & Deconvolution**: 1D system impulse response operations.
