# Machine Learning Models & Features

## Feature Vectors
- **Audio Features**: Mean amplitude, Standard Deviation, Zero Crossing Rate, Spectral Centroid.
- **Image Features**: Mean Intensity, Variance/Std, Minimum Pixel Value, Maximum Pixel Value.

## Classifiers
- Scalers and Classifiers are serialized using `joblib`/`pickle` under `models/audio/` and `models/image/`.
