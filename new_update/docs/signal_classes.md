# Supported Signal Classes

SPANDHAN categorizes signals into five primary standard benchmark types:

1. **Impulse**: Delta functions, sharp transients, impact responses.
2. **Sinusoidal**: Pure tone harmonics, single or multi-frequency sines.
3. **White Noise**: Gaussian random signal across full bandwidth.
4. **Step**: Heaviside step transitions, level changes.
5. **Chirp**: Swept-frequency cosine signals.
